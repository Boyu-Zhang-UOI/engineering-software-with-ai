Tool Handout ​

Checked 2026-11-02. Free tiers change monthly. The instructor re-checks every row before each term and again before week 9 (re-check before every term). Found something out of date? Open a "tool change" issue.

This is the only file in the course that names model versions, prices, credit amounts, rate limits and the dates of tool changes (the two-layer rule). Everything else names products only when a step needs them, and points here for the numbers.

Labels. Facts were checked on 2026-11-02 unless marked [A], which means carried over from the sibling course's handout (checked 2026-10-21) and not re-checked. [3rd] means the source is a third party (press, a blog, a tracker), not the vendor. UNVERIFIED means the course could not confirm it. Sources for every row: Course B ("Engineering Software with AI"): the $0 tool landscape, checked 2 November 2026 and the November 2026 landscape report.

The headline. On a $0 budget the scarce resource is model capacity, not tools. Every harness worth teaching is free and open source; the free inference attached to them is small. Copilot Student's model allowance is reported at about $2 a month, and a single default-effort Copilot code review averages $1.50. So the course spreads heavy agent work across several separate free pools, plus a lab machine running local models (how).

The lab machine and local models ​

The instructor arranges a lab machine with a 24–32 GB GPU running Ollama before the term, served to the class as one shared queue. How to use it, and how to run a model on your laptop: Local Models: Ollama on a Laptop and on the Lab Machine.

The configuration trap. Ollama's default context is 4K tokens when VRAM is under 24 GiB, 32K at 24–48 GiB and 256K at 48 GiB or more. Ollama's docs say agents and coding tools "should be set to at least 64000 tokens", and "OpenCode requires a context length of 64k or higher". Start the server with OLLAMA_CONTEXT_LENGTH=64000 ollama serve. Without it, the system prompt is truncated and tool calls fail silently (Ollama docs). Current Ollama: v0.40.13 (28 Oct 2026).

What local models are good for. Tool calling depends on training more than size: in one test, small Qwen models "output bash commands instead of invoking" OpenCode's write tool [3rd]. 9–27B models work for the student-built agent, MCP tool-call testing, evals (as cheap judges or subjects) and small fixes. They are not a substitute for frontier models when navigating a large codebase. Michigan's EECS 498 runs at $0 on small local models on purpose: "A small model punishes sloppy engineering visibly; that is the point" [A].

Free harnesses against Ollama. Claude Code (free binary, v2.1.317 on npm, Node 22 or later) and OpenCode both run against a local Ollama: ollama launch claude or ollama launch opencode, or set ANTHROPIC_BASE_URL=http://localhost:11434 and ANTHROPIC_AUTH_TOKEN=ollama yourself (Ollama: Claude Code; Ollama: OpenCode). Whether Copilot CLI's /model route to Ollama consumes credits is UNVERIFIED.

Without the lab machine, the course runs on the free API tiers (Gemini, Groq, OpenRouter) and laptop models (gemma4:e4b/12b), and week 13's parallel lab uses Jules plus fewer local agents.

Free infrastructure ​

GitHub Actions. Since the 28 Oct 2026 change, Actions uses a dollar-denominated compute entitlement shared with Copilot cloud sandboxes: $12/month on GitHub Free, $18 on Pro (students). Rates: Linux 2-core $0.006/min, Windows $0.010/min, macOS $0.062/min. Standard runners are free in public repositories and don't reduce the allowance; self-hosted runners are free; larger runners are billed even in public repositories (Actions billing).

Codespaces. Free: 120 core-hours (about 60 hours on 2 cores) and 15 GB. Pro: 180 core-hours (about 90 hours) and 20 GB (Codespaces billing).

Code security at $0 on public repositories. CodeQL code scanning, Copilot Autofix, secret scanning, push protection and Dependabot updates are free on public repositories. Private repositories need Code Security ($30 per active committer per month) or Secret Protection ($19). New public previews (28 Oct 2026): "AI Scan" for languages CodeQL doesn't support, and code scanning for AI apps (GitHub security plans). CodeQL bundle v2.27.4.

Static analysis. Semgrep Community Edition's engine is LGPL-2.1 (v1.183.0), but the Semgrep-maintained rules are under the Semgrep Rules License (internal, non-SaaS use only), and cross-file taint analysis is paid. Semgrep's platform Free Edition: 10 contributors, 10 repositories, 60 AI credits; secrets scanning needs Teams (Semgrep pricing). Opengrep (LGPL fork) v1.33.1. Ruff 0.17.3.

Testing tools (all free and open source): StrykerJS v10.1.1 (Apache-2.0, Node 22 or later) · mutmut 3.8.1 (Python 3.10+) · PIT 1.30.1 · Cosmic Ray 8.7.0 · Hypothesis 6.170.14 (Python 3.11+) · fast-check 4.10.2 (MIT).

Evals and tracing. promptfoo 0.125.1 (MIT, Node 22.22 or later; OpenAI announced its acquisition on 9 Mar 2026 and says it stays MIT) · Inspect AI 0.3.287 (MIT, Python 3.11+) · DeepEval 4.3.2 · Langfuse (MIT core; owned by ClickHouse since Jan 2026; self-hosting free; Cloud Hobby 50K units/month, 2 users, 30 days of data) · Arize Phoenix v21.0.0 (Elastic License 2.0; AX Free: 25K spans/month, 15-day retention). OpenAI Evals has had no push since 14 Apr 2026: treat it as dormant.

MCP. Current spec version 2026-07-28, with a stateless core: no initialize handshake, an optional server/discover, and the version carried in each request's _meta or the MCP-Protocol-Version header. Deprecated features stay at least 12 months. The roadmap (22 Aug 2026) gives no date for the next version; a redesigned tools/call result is on it, so don't grade the exact content/structuredContent shape (versioning). SDKs: TypeScript v2 (@modelcontextprotocol/server and @modelcontextprotocol/client, v2.4.0, Node 20+); the old @modelcontextprotocol/sdk (v1.32.2) gets security fixes until at least late January 2027, so 2025 tutorials that import @modelcontextprotocol/sdk/server/mcp.js are on the legacy line. Python v2 (mcp 2.3.0, Python 3.11+, from mcp.server import MCPServer). MCP Inspector 2.13.0 (Node 22.19+). Copilot includes MCP on Free and Student.

Sandboxing. Copilot local sandboxing went generally available on 7 Oct 2026 at no extra cost: off by default, turn it on with /sandbox enable; needs macOS 15+, bwrap 0.5.0+ on Linux, or a recent Windows 11 build. Docker Sandboxes (sbx, a microVM per agent) is free locally. Docker Desktop is free for educational use. gVisor release-20261102.0.

Versions to standardize on: Node 22.22 or later and Python 3.12. The kits run on Node 20.12+, but StrykerJS (week 7), promptfoo, MCP Inspector, the MCP v2 SDKs and Hypothesis need the newer versions.

GitHub Agentic Workflows (generally available 28 Oct 2026 on Free, Team and Enterprise): workflows written in Markdown and compiled to Actions YAML; engines Copilot, Claude, Codex or Gemini, each with its own secret; read-only by default, with safe-outputs. The default max-ai-credits is 1,000 ($10) per run, five times a Student's monthly allowance. Set it far lower before you run anything (safety contract rule 6; docs).

Re-check before every term ​

Free tiers change faster than terms. Before each term, and again before week 9, the instructor uses every primary and fallback tool, not just reads about it, and updates this file. For each row: does a new account still get it? Is the allowance the same? Has the data-use term changed? Did anything in known upcoming changes happen? Then change the date at the top of this page, and tell the class what changed. A change of tool belongs here; a lesson should never need editing because a product changed.

Also try these three, which week 9 relies on and which couldn't be verified on 2026-11-02:

  • CodeRabbit: does commenting @coderabbitai review start a review on a pull request opened before the app was installed? (Week 9 opens the PRs first, then installs it.)
  • Semgrep Community Edition: does semgrep scan --baseline-commit [commit] still report only the findings introduced since that commit, as week 9's CI job expects?
  • GitHub rulesets: is the branch-ruleset rule Require code scanning results available for free public repositories, including team forks owned by the course organization?
