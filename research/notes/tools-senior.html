Course B ("Engineering Software with AI"): the $0 tool landscape, checked 2 November 2026 ​

Scope. These notes cover only what is new or different from Course A's handout (TOOLS.md, verified 2026-10-21) and its notes (research/notes/2026-10/tool-changes-since-september.md, research/notes/tools-ide-cli-apis-hosting.md). Course B students are adults (CS seniors and graduate students), so 18+ rules are not a blocker. Their work is heavier, though: agent loops on large codebases, MCP servers, CI, code review and evals.

Dates and labels.

  • Every fact was checked on 2026-11-02 unless it is tagged [A], which means it was carried over from Course A's notes dated 2026-10-21 and was not re-checked.
  • [official]: the vendor's own page.
  • [3rd]: press, blogs or trackers.
  • [snippet]: seen only in a search summary.
  • [GH]: read from the GitHub API or the npm/PyPI registries on 2026-11-02 (UTC timestamps).
  • UNVERIFIED marks anything that could not be confirmed.

The headline finding. On a $0 budget, the scarce resource is model capacity, not tools. Every harness worth teaching is free: VS Code, Copilot CLI, Gemini CLI, OpenCode, Cline, Goose, the MCP SDKs, CodeQL, Semgrep, Stryker and promptfoo. The free inference attached to them is small. Copilot Student is about $2/month of model usage, and a single default-effort Copilot code review averages $1.50. Groq's free tier allows 8K tokens per minute, and OpenRouter's free models allow 50 requests a day. The course design therefore has to spread work across several separate free pools, plus a local or lab-served model.

3. Local models for agentic coding ​

Configuration trap (official):

  • Ollama's default context is 4K when VRAM is under 24 GiB, 32K at 24–48 GiB, and 256K at 48 GiB or more.
  • The docs say agents and coding tools "should be set to at least 64000 tokens". Set it with OLLAMA_CONTEXT_LENGTH=64000 ollama serve.
  • Without that, tool calls silently fail because the system prompt gets truncated.
  • Ollama is at v0.40.13 (28 Oct 2026) [GH].
  • Ollama context length.

Quality notes, stated plainly ​

  • Tool calling depends on the model's training, not its size. One test found that Qwen3.5 9B and 4B "output bash commands instead of invoking" OpenCode's write tool. Another guide found devstral-small-2 "too small for reliable function calls in OpenCode". imagewize/ollama-opencode-setup [3rd]; summary [3rd].
  • A precedent for teaching with weak local models. UMich EECS 498 AASE (Fall 2026) is $0 by design, using qwen3.5:4b or :9b with Aider. Its stated reason: "A small model punishes sloppy engineering visibly; that is the point". Lab machines serve students whose laptops can't run the models. UMich syllabus [A].
  • Inference: 9–27B local models work for the student-built agent, MCP tool-call testing, evals (as cheap judges or subjects) and small fixes. They are not a substitute for frontier models when navigating large open-source codebases.
    • One consumer GPU serving a whole class gives you one shared queue. Plan for team-sized batches, not 30 concurrent agent loops.
    • Copilot CLI can list a running Ollama's models through /model [A], but whether this consumes credits is UNVERIFIED.

5. MCP in late 2026 ​

  • Spec status: the current version is 2026-07-28. It has a stateless core: no initialize handshake, an optional server/discover, and the version carried in every request's _meta or in the MCP-Protocol-Version header.
    • Deprecated features stay at least 12 months (90 days under the expedited-removal exception).
    • The roadmap (updated 22 Aug 2026) gives no date for the next version. Its priorities are agentic messaging (Tasks and events), HTTP over stdio, agent identity (DPoP, workload identity), a redesigned tools/call result shape, and progressive discovery.
    • Inference: expect a tools/call change within a year. Avoid grading on the exact content/structuredContent shape.
    • Versioning; roadmap [official].
  • SDKs:
    • Tier 1: TypeScript, Python, C#, Go, Rust and Ruby (Ruby promoted 30 Oct 2026). Java is Tier 2; Swift, PHP and Kotlin are Tier 3. SDK list, MCP blog [official].
    • TypeScript v2 (the stable line since 27 Jul 2026, for spec 2026-07-28) is split into @modelcontextprotocol/server and @modelcontextprotocol/client (v2.4.0, Node ≥20). Schemas use Standard Schema (Zod v4 and others). The old @modelcontextprotocol/sdk (v1.32.2) gets security fixes "for at least six months after the v2 release", so at least until late January 2027. Any 2025 tutorial that imports @modelcontextprotocol/sdk/server/mcp.js is on the legacy line. TS SDK README [GH].
    • Python v2 (mcp 2.3.0, Python ≥3.11) uses from mcp.server import MCPServer and runs with uv run mcp dev server.py. The FastMCP-era imports in older tutorials are outdated. Python SDK README [GH].
  • Building and testing a server at $0:
    1. Write a 15-line server with the Python or TypeScript SDK.
    2. Exercise it in MCP Inspector (2.13.0, Node ≥22.19), via mcp dev or npx @modelcontextprotocol/inspector.
    3. Unit-test it with the SDK's own Client, which can launch a stdio subprocess.
    4. Connect it to the student's own agent (Gemini or Groq key, or Ollama), to Copilot in VS Code (MCP included on Free and Student), and to Gemini CLI or OpenCode.
    5. For remote HTTP servers, run them locally first; hosting is in TOOLS.md.
  • Security issues to teach:
    • The spec's own attack catalogue (Security Best Practices, 2026-07-28): confused deputy; token passthrough (forbidden); SSRF during OAuth discovery, including cloud metadata at 169.254.169.254; state-handle hijacking; local MCP server compromise (malicious startup commands, DNS rebinding of localhost servers); javascript: or shell injection through authorization URLs; stdio proxy escalation; mix-up attacks; localhost redirect impersonation; and scope minimisation.
    • Incidents in Course A's notes [A]: agents launching MCP servers declared in untrusted repo configs (GHSA-m84r-3mrm-j4p8); an OAuth credential leak in the TypeScript SDK (GHSA-6qxp-vccf-f47h); a fake "MCP security audit" npm package that registered an attacker's server; up to 15 lookalike servers per verified server (UpGuard). The advisory pages were not opened; verify them before using them on slides.

The biggest risks, ranked:

  1. Copilot Student's roughly $2/month credit pool and $1.50 average code reviews.
  2. The Gemini free tier's unpublished, changeable limits and training on data, while it carries most of the heavy agent load.
  3. Copilot "paid plans only" cloud features (from 28 Oct), whose status for Student is unknown.
  4. Upstream projects throttling AI-assisted PRs.
  5. Local models that are too weak for agentic work on large codebases.
  6. Deadlines: the Google AI Pro offer must be redeemed by 31 Dec 2026, Codex credits expire after 12 months, the Zed Student year runs out, and TypeScript MCP v1 support ends around late January 2027.
